مِرصاد V7 — تشغيل تلقائي متسلسل وخط زمني
جديد في V7
زر بدء التشغيل المتسلسل يتابع صفحات سحب المتابعين ثم فحص About تلقائيًا، 50 حسابًا كحد أقصى في دورة الإثراء الواحدة، ثم يبدأ الدورة التالية دون ضغطة جديدة.
أزرار تشغيل/إيقاف، وحد نهائي للحسابات الفريدة، وسقف إجمالي صفحات جلب المتابعين، مع احترام الحد التراكمي لطلبات About الذي سبق تحديده في V6.
عداد مستقل للمتابعين والإثراء، وعدد الصفحات، والوقت المنقضي منذ إنشاء المهمة، وتقدير متغير للوقت المتبقي بحسب السجلات الفريدة المرصودة، وخط زمني وسجل آخر الدفعات.
كل دورة تحفظ تقدمها في SQLite؛ عند إعادة فتح الموقع يمكن الاستكمال من آخر مؤشر معروف، طالما أن قاعدة البيانات لم تُحذف.
عند 401/403/429 أو تكرار مؤشر الصفحة يوقف التنفيذ الآلي ولا يرسل طلبات متكررة بلا حدود. عند انتهاء سقف About يوقف الإثراء ويوضح السبب.
رفع الملفات
افحص نسخة مشروعك الحالية وتأكد من وجود ملفات V6 وهي `auto_enrich.py`، `rapid_client.py`، `core.py`، `exporter.py` و`x_client.py`.
في مستودع GitHub `baseer155/mirsad-x` استبدل `app.py` بالملف المرفق وأضف `auto_runner.py`.
إذا لم يكن `auto_enrich.py` موجودًا في المستودع، أضف نسخته المرفقة؛ إذا كان موجودًا ويعمل فاحتفظ بنسختك.
لا ترفع ملف ZIP نفسه ولا تضع مفاتيح API أو كلمة مرور داخل الملفات.
احفظ Commit؛ أعد فتح Streamlit وأدخل لوحة المسؤول ثم افتح مهمة موجودة في «سحب متابعي X».
افتح «الميزانية وضبط الإثراء»، وعيّن سقف طلبات About والتكلفة التقديرية ثم احفظ الميزانية.
في «تشغيل متسلسل تلقائي» اختر الهدف وسقف صفحات السحب ثم اضغط بدء التشغيل المتسلسل مرة واحدة. ستتكرر الدفعات تلقائيًا.
حدود التشغيل المهمة
هذا ليس عامل مهام في الخلفية. يعمل بواسطة `st.fragment(run_every='4s')` بينما تبويب الموقع مفتوح ومرتبط وجلسة Streamlit نشطة. عند إغلاق التبويب، انقطاع الاتصال، إعادة نشر التطبيق، أو نوم التطبيق المجاني قد يتوقف التنفيذ. للتحكم وتشغيله بعد إغلاق المتصفح أو على مدار الساعة، استخدم PostgreSQL وتطبيق عامل مهام مستقل على خدمة استضافة مناسبة، مع طابور وتوقيف مركزي. لا تُعتبر حزمة V7 حلًا لخلفية التشغيل الدائم.
يتم إرسال طلب منفصل عادةً لكل حساب ضمن دفعة About، وليس طلبًا واحدًا لكل 50 حسابًا. رسوم RapidAPI الحقيقية تستند إلى خطة المزود؛ حساب التكلفة المعروض تقديري ولا يحمي من الرسوم خارج الطلبات التي يتحكم بها مِرصاد. السقف الافتراضي لصفحات المتابعين 250 صفحة للحماية، ويمكنك زيادته عمدًا إذا كانت الحصة والتكلفة تسمحان.
التوقيت التقديري مبني على معدل السحب المحقق منذ بدء إنشاء المهمة، وقد يكون غير دقيق خصوصًا مع التوقف أو اختلاف سرعة API. لا يمكن ضمان استخراج العدد النهائي إذا انتهت صفحات المزود أو تجاوزت الحدود.
التخزين: SQLite على Streamlit Community Cloud قد يكون مؤقتًا، وبالتالي قد تضيع الحالة بعد إعادة التشغيل. لا تعتمد على المهام الطويلة بدون تخزين دائم ونسخة احتياطية.
الأسرار: احتفظ بالإعدادات `ADMIN_PASSWORD`, `RAPIDAPI_KEY`, `RAPIDAPI_FOLLOWERS_PATH`, `RAPIDAPI_ABOUT_PATH` في Secrets فقط. يجب تغيير القيم التي كُشفت في صور سابقة.
اختبار بلا طلبات مدفوعة
```bash
python -m py_compile app.py auto_runner.py auto_enrich.py
python test_auto_runner.py
```
الاختبار يستخدم مصدرًا وهميًا، ولا يختبر اتصال RapidAPI الحقيقي.
