مِرصاد V17 — المرحلة الرابعة: التقارير المعتمدة
التثبيت
تتضمن الحزمة أربعة ملفات للإنتاج:
`app.py`: واجهة V17 الأحدث بعد إصلاح التشغيل الجماعي، مع توضيح حالة التحقق عند التصدير.
`exporter.py`: إضافة شيت «التحقق من التقرير» إلى Excel، وشيت «اعتماد الحسابات المستهدفة» لتقرير المجموعة.
`report_export.py`: إضافة صفحة أو شريحة تلخص التحقق إلى Word وPowerPoint.
`report_audit.py`: إنشاء بيان تحقق من بيانات المهمة المحفوظة وتقييم جاهزيتها.
خذ نسخة احتياطية من مشروعك وقاعدة البيانات أولًا.
ارفع الملفات الأربعة إلى جذر مستودع GitHub الخاص بالموقع.
احتفظ بـ `rapid_client.py` مع إصلاح الاستجابة المثبّت سابقًا، وباقي ملفات المرحلة الثانية والثالثة (لا تستبدلها).
تأكد من وجود `readiness.py` و`filtering.py` و`report_fields.py` وملفات السحب الموجودة مسبقًا.
اضغط Commit changes، ثم راجع تشغيل Streamlit وقم بتجربة تقرير أولي لمهمة غير مكتملة ثم تقرير نهائي لمهمة مكتملة.
قواعد التحقق
«نهائي معتمد»: لا يظهر إلا بعد تأكيد نهاية صفحات السحب وحالة اكتمال جميع فحوص About المسجلة، دون فحوص معلقة أو مستنفدة أو سجلات تحتاج يوزر.
«أولي غير معتمد»: يظل قابلًا للتنزيل حتى عندما لا تكتمل هذه الشروط، مع بيان السبب.
الحسابات غير محددة الدولة وفق حقل `account_country` المستخرج من About فقط لا تدخل الجداول والإحصاءات النهائية؛ تظل محفوظة لإعادة المحاولة.
خانة «متصل عبر» تُحفظ وتُصدر كما أعادها المزود، ولا يتم افتراضها.
روابط الحساب/المعرف الدائم/حول الحساب كنصوص كاملة في Excel، والمعرف الرقمي كنص.
شيت «الحسابات المكررة» والتداخل محفوظان في تقرير المجموعة، وتضاف أوراق تحقق منفصلة.
مرجع التحقق الداخلي بصمة للبيان وقت التصدير، ليس توقيعًا رقميًا أو توثيقًا من X أو RapidAPI.
حدود التطبيق
يتم تقييم حالة الاعتماد حسب البيانات المخزنة وقت إنشاء الملف؛ يمكن أن تتغير حالة المهمة بعد ذلك.
لا تضمن حالة «نهائي معتمد» أن المزود قد أتاح جميع متابعي X فعلًا؛ تعكس انتهاء الصفحات المبلغ عنه من المزود والفحوص المسجلة.
التقرير الجماعي بصيغة Excel؛ تقارير Word وPowerPoint تخص حاليًا كل مهمة فردية. لم نضف هنا مولدًا جماعيًا جديدًا لملفي Word/PowerPoint.
اعتماد التقرير لا يعوّض الحاجة إلى تشغيل العامل المستقل وقاعدة بيانات دائمة على استضافة تدعم ذلك.
لم يتم إجراء اختبار تكاملي على RapidAPI أو على الموقع المنشور.
الاختبارات
اختُبر إنشاء التقرير الفردي الأولي والنهائي، ووجود بيان التحقق في Excel وWord وPowerPoint، وعدم إنشاء روابط Excel تشعبية، واعتماد مجموعة حسابين وإظهار ورقتي «الحسابات المكررة» و«اعتماد الحسابات المستهدفة».
