مِرصاد — إصلاح بيانات «حول الحساب» V4
ما الجديد؟
تغيير استعلام Twttr API من User ID إلى username الصحيح لخدمة `GET /about-account`.
اختبار حساب واحد يعرض أسماء مفاتيح الاستجابة والتصنيفات المستخرجة، دون كشف المفتاح.
معالجة دفعات صغيرة للمعلومات المتاحة وتسجيل تاريخ آخر فحص لكل حساب وتفادي إعادة الفحص تلقائيًا.
عدم الخلط بين الموقع المكتوب بالملف الشخصي ودولة «حول الحساب».
عدم افتراض أن الحساب موقوف أو نشط بسبب استجابة فارغة.
تثبيت التحديث على المستودع
استبدل `app.py` و`rapid_client.py` و`core.py` و`exporter.py` الموجودة في جذر المستودع. الملف `x_client.py` و`requirements.txt` لا يحتاجان إلى تغيير. بعد Commit، تحقق من إعادة تشغيل Streamlit.
إعدادات Secrets
```toml
ADMIN_PASSWORD = "<your new private password>"
RAPIDAPI_KEY = "<your rotated RapidAPI key>"
RAPIDAPI_FOLLOWERS_PATH = "/followers"
RAPIDAPI_PROFILES_PATH = "/get-users"
RAPIDAPI_ABOUT_PATH = "/about-account"
```
بما أن المفتاح وكلمة مرور المشرف ظهرا في صور سابقة، استبدلهما بقيم جديدة. لا تضع المفاتيح في المستودع أو في المحادثة.
التجربة
افتح تبويب «التقارير وExcel» واختر مهمة بها يوزرات صحيحة.
افتح «فحص حول الحساب» واضغط «اختبار حول حساب واحد» مرة واحدة.
إذا أظهر `any_about_value=true` فعّل فحص 3 حسابات فقط، ثم راجع الملف.
إذا كان `false`، توقف عن طلب المزيد. على الأرجح أن مزود الخدمة لا يعيد هذه المعلومات أو أن بنية الرد مختلفة. راجع مفاتيح JSON في نتيجة الفحص.
الحدود
«الدولة حسب حول الحساب» ليست الجنسية أو الإقامة القانونية، وقد تكون منطقة لا دولة.
«متصل عبر» ليس مضمونًا في كل الحسابات أو الإصدارات.
«حالة الإيقاف» تحتاج دليلًا صريحًا أو خدمة فحص حالة مستقلة؛ صفحة About لا تضمنها، والحسابات التي لا تظهر لا تُصنّف موقوفة.
يحتسب كل استعلام About غالبًا طلبًا من اشتراك RapidAPI. فحص 50,000 حساب قد يعني ما يصل إلى 50,000 طلب إضافي؛ تحقق من حدود الباقة قبل الرفع.
Streamlit Community Cloud قد لا يحفظ SQLite محليًا بعد إعادة التشغيل. استخدم قاعدة بيانات دائمة لتشغيل مستمر.
