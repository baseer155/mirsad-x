مِرصاد V17 — المرحلة الثالثة: إعادة تصميم الواجهة العربية
التثبيت
احتفظ بنسخة احتياطية من ملفات المستودع وقاعدة البيانات.
استبدل `app.py` في جذر المستودع بهذا الملف.
إذا لم تكن قد طبقت إصلاح استجابة المزود الأخير، استبدل أيضًا `rapid_client.py` المرفق. إذا سبق تطبيقه فلا داعي لاستبداله مجددًا.
لا تستبدل `core.py` أو `multi_accounts.py` أو `auto_runner.py` أو `auto_enrich.py` أو ملفات التقارير، ولا تغير الأسرار.
ارفع الملفات إلى GitHub وأعد نشر تطبيق Streamlit.
التحسينات
تثبيت مسار العربية RTL وتوحيد المسافات والخطوط والبطاقات.
إزالة ازدحام رأس الصفحة وتقليل النصوص التوضيحية.
واجهة السحب بخيار واضح: «مجموعة حسابات» أو «حساب واحد» بدل عرض النموذجين معًا.
وضع خيارات السحب الجماعي التقنية داخل «إعدادات السحب والإثراء المتقدمة».
وضع إعدادات الصفحة وRapidAPI الفردية داخل أقسام متقدمة.
إخفاء ميزانية About الفردية افتراضيًا مع بقاء عملها كما كان.
تحسين عرض المقاييس الطويلة وحقول الإدخال في الشاشات الصغيرة.
الحفاظ على سير العمل وسجلات المهام والتقارير والعامل الخارجي من المرحلة السابقة.
عندما لا يوفر المصدر إجمالي المتابعين، يظهر عدد المستخرجين فقط في البطاقة بدل الهدف الاحتياطي مليون.
حدود الاختبار
تم فحص صياغة Python والبنية الشرطية للصفحات والتحقق من بقاء مسارات الوظائف. لم يُجر اختبار متصفح على Streamlit Cloud أو تشغيل فعلي لطلبات RapidAPI. قد تتغير معرفات CSS الداخلية مع تحديث Streamlit؛ تحقق من الواجهة على هاتف وحاسوب بعد النشر.
