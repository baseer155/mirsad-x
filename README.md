مِرصاد — معالجة اختلاف استجابة مزود المتابعين
التركيب
احتفظ بنسخة من ملفات مشروع V17.
استبدل ملف `rapid_client.py` في جذر المستودع بالملف المرفق فقط.
اضغط Commit changes، ثم أعد اختبار سحب دفعة صغيرة.
لا تغيّر ملفات المرحلة الأولى ولا مفاتيح API.
التغييرات
دعم أغلفة X GraphQL المتداخلة (مثل `timeline_v2`)، وقوائم `followers` و`users` وبعض استجابات `data` المباشرة.
التعرف على مؤشر الصفحة التالي عند وجوده، وعدم اعتباره حسابًا.
رفض استجابات أخطاء المزود أو الصيغ المجهولة بدل الادعاء بأن جميع المتابعين انتهوا.
عرض أسماء حقول جذر الاستجابة عند عدم التعرف عليها، دون إرسال المحتوى أو المفاتيح.
حفظ كل المعرفات الدائمة كنصوص وعدم تغيير منطق الإثراء.
مهم
لا نملك عينة JSON الفعلية للاستجابة التي تسببت في الخطأ، لذلك نجاح هذا الإصلاح على المزود الحقيقي غير مؤكد. إذا ظهرت رسالة اختلاف الصيغة مجددًا، احفظ هيكل المفاتيح فقط أو احجب مفاتيح API والمعلومات الشخصية قبل مشاركة الاستجابة. تحقق من أن `RAPIDAPI_FOLLOWERS_PATH` يشير لمسار جلب المتابعين في اشتراكك، لا `/user` أو `/get-users`.
