# مِرصاد | ذكاء المنصات الاجتماعية

موقع عربي مستقل عن Apify وRapidAPI، بواجهة عامة ولوحة مسؤول خاصة، وسحب متابعي X عبر **X API الرسمي** عند توفر صلاحيات المطور، مع استيراد CSV لثلاث منصات، وقاعدة SQLite، وتصدير Excel احترافي من خمس أوراق.

## بدء التشغيل محليًا

1. ثبّت Python 3.11 أو أحدث.
2. شغّل `pip install -r requirements.txt`.
3. انسخ `secrets.example.toml` إلى `.streamlit/secrets.toml` ثم ضع كلمة مرور قوية ورمز X API رسميًا. **لا ترفع ملف الأسرار إلى GitHub**.
4. شغّل `streamlit run app.py`.
5. ادخل على الرابط المحلي الذي يظهر ثم سجل الدخول من الشريط الجانبي.

## النشر العام

1. أنشئ مستودع GitHub جديدًا وارفع محتويات المجلد (لا ترفع أسرارًا أو ملف قاعدة البيانات).
2. افتح https://share.streamlit.io/ واختر Create app ثم المستودع وملف `app.py`.
3. ضمن **Advanced settings → Secrets** أضف:

```toml
ADMIN_PASSWORD = "A_LONG_RANDOM_PASSWORD"
X_BEARER_TOKEN = "YOUR_OFFICIAL_X_BEARER_TOKEN"
```

4. اضغط Deploy. الموقع العام يعرض صفحة تعريفية فقط؛ ولا تظهر السجلات والتصدير إلا بعد دخول المسؤول.
5. إذا لم تكن لديك صلاحيات X API يمكنك حذف `X_BEARER_TOKEN`؛ سيظل استيراد CSV والتقارير يعملان.

## استخدام X

- أدخل `@username` أو رابط الحساب، أنشئ مهمة، ثم نفّذها على دفعات (حتى 20 صفحة في كل تشغيل).
- يعتمد طلب المتابعين على `GET /2/users/:id/followers` مع `pagination_token`، وحقول الملف الشخصي المتاحة. يحتفظ النظام بالمؤشر والسجلات المكتملة حتى يمكن استئناف الدفعة التالية.
- الرقم `50,000` يمثل هدف معالجة وليس ضمانًا لوصول X API إلى القائمة كاملة؛ يتوقف ذلك على صلاحياتك والحدود والتكلفة.

## ملاحظات تقنية ومصداقية

- نظام الدول الحالي **تقديري** من حقل الموقع الذي يكتبه صاحب الحساب. ليس دولة إنشاء الحساب، ولا الجنسية، ولا موقع المستخدم الحقيقي. رابط «حول الحساب» يدرج لكل سجل في Excel للفحص اليدوي فقط.
- الحساب المحمي ليس موقوفًا. لا نستنتج إيقاف الحسابات أو «متصل عبر» أو دولة About من بيانات لم يرجعها المصدر.
- يدعم التصميم معالجة +50 ألف **سجل محفوظ** مع معرفات نصية وتمييز التكرار؛ لكن سرعة الاستخراج وعمله الفعلي غير مضمونة دون مفاتيح واختبارات ميدانية.
- ملفات SQLite على استضافة مجانية قد تُحذف بعد إعادة التشغيل؛ استخدم استضافة ذات تخزين دائم وقاعدة PostgreSQL وعمال مهام إذا أردت تشغيلًا مستمرًا متعدد المستخدمين. إصدار SQLite الحالي مناسب لتشغيل أولي محدود.
- كلمة المرور الواحدة حماية مبدئية وليست بديلًا لنظام صلاحيات احترافي متعدد المستخدمين أو حماية من محاولات التخمين. يُنصح ببوابة مصادقة خارجية عند نشر نظام حساس.
- إذا ظهر مفتاح RapidAPI في صورة سبق مشاركتها، ألغِه وأنشئ آخر، حتى إن لم يستخدمه مِرصاد.

## أوراق Excel

1. **المتابعون:** الاسم، اليوزر، المعرف الدائم كنص، رابط المعرف الدائم، رابط الحساب، رابط About، الموقع المعلن، الدولة التقديرية، حالة الحماية، التوثيق، الأرقام المتاحة.
2. **تحليل الدول:** عدد ونسبة الحسابات ومخطط.
3. **الحسابات المحمية:** أعداد ونسب حسب الدولة.
4. **الخط الزمني:** الدفعات وأوقاتها وحجمها.
5. **المنهجية والقيود:** تعريف البيانات ومصدرها وقيودها.

## اختبار دون أي اشتراك

شغّل `python -m unittest discover -s tests -v` ثم استورد ملف CSV من داخل الموقع. هذا الاختبار لا يرسل أي طلب إلى X.
