مِرصاد V8 — قائمة يمينية عربية + تحسين متابعة السحب
التثبيت
ارفع app.py و auto_runner.py من هذا الملف إلى جذر مستودع GitHub بدل النسخ السابقة، مع إبقاء `auto_enrich.py` وملفات `core.py` و`rapid_client.py` و`exporter.py` الحالية. اضغط Commit changes، ثم انتظر تحديث Streamlit أو أعد تشغيل التطبيق.
تحسينات التصميم
قائمة رئيسية عمودية في يمين الشاشة: الرئيسية، سحب المتابعين، استيراد البيانات، التحليلات والتقارير، دليل المنصات.
واجهة عربية RTL بخط Tajawal عند توفر الاتصال، وبخطوط محلية احتياطية.
تمييز الخيار النشط، بطاقات مؤشرات، تنسيقات أفضل للكمبيوتر والجوال.
حقول المعرفات والروابط والجداول الرقمية تبقى LTR حتى لا تُقلب أرقام UID.
تحليل الدول مبني على `account_country` من فحص About، لا على الموقع المعلن.
تنبيه بخصوص التوقف عند 191 حسابًا
في سجل المستخدم، ظهرت 191 حسابًا فريدًا ثم اختفت الصفحات الجديدة. هذه المشكلة قد تكون نهاية صفحات المورد/حد تغطية الاستعلام وليست خللًا في التبويبات. النسخة الجديدة تشرح سبب انتهاء النتائج إذا انتهت صفحات المزود عند عدد أقل من الهدف. لا يمكن ضمان 50,000 بمجرد تعيين الهدف، ولا ينبغي إعادة الاستعلام بلا حد إذا لم يعد مصدر البيانات صفحات جديدة.
الاستئناف والحدود
`auto_runner.py` يحتفظ بالمنطق الحالي للتوقف عند نهاية الصفحات أو انتهاء الميزانية أو خطأ API.
بعد كل دفعة About تُحفظ النتائج. فحص 50 حسابًا قد يتوقف داخليًا مبكرًا بسبب حد الزمن، أو انتهاء الميزانية.
`Streamlit` ليس عامل مهام دائمًا؛ تشغيل جلسة طويل قد يتوقف بسبب انقطاع المتصفح أو إعادة تشغيل الخادم.
قاعدة SQLite على Streamlit Community Cloud قد تكون مؤقتة، ولذلك يجب نسخ التقارير وتوفير قاعدة دائمة قبل التشغيل الإنتاجي.
الأمان
المفاتيح وكلمات المرور تبقى في Streamlit Secrets فقط. ينبغي تدوير المفتاح وكلمة المرور اللذين ظهرا سابقًا في صور المحادثة.
